Política de privacidade

Atualizada em 11 de outubro de 2026

Este site (pedroazara.vercel.app) é o portfólio pessoal de Pedro Henrique Almeida. Ele também tem um painel privado, o Painel, que só o dono do site usa para organizar a própria rotina. Esta página explica quais dados passam pelo site e o que é feito com eles.

Visitantes do site

  • Não há cadastro para visitantes e o site não usa cookies de publicidade.
  • Quando ativada, a contagem de visitas usa o Umami, que não usa cookies, não identifica pessoas e respeita o "Não rastrear" do navegador.
  • Erros técnicos podem ser enviados ao Sentry sem nome, e-mail, endereço da página ou outros dados pessoais.
  • As preferências de idioma e de tema ficam guardadas só no seu navegador.

Conexão com o Google Agenda

No Painel, o botão Conectar com Google pede permissão para ver e editar os eventos da agenda principal da conta Google (escopo calendar.events). Com essa permissão, o Painel:

  • lê os compromissos dos próximos 14 dias para mostrá-los na tela;
  • cria um compromisso novo na agenda quando o próprio usuário pede, pelo botão Novo compromisso.

Os eventos lidos por essa conexão não são gravados em banco de dados: o servidor os busca no Google a cada consulta e os entrega direto ao navegador. A autorização do Google fica cifrada num cookie do próprio navegador, que só o servidor do site consegue abrir.

Os dados do Google não são vendidos, compartilhados com terceiros, usados para publicidade nem usados para treinar modelos de inteligência artificial.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso

O botão Desconectar no Painel revoga a permissão no Google e apaga o cookie. Também é possível remover o acesso a qualquer momento em myaccount.google.com/permissions.

Login no Painel

O acesso ao Painel usa uma conta no Supabase, o serviço que guarda o conteúdo do site. Só o dono do site tem essa conta.
