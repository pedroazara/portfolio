# Identidade visual

Cores tiradas de `src/index.css` do portfólio. As capas precisam parecer parte
da página, não um banner colado nela.

## Estilo

- Ilustração vetorial limpa e técnica: esquemas, instrumentos, circuitos,
  ondas, trajetórias, pontos de dados, redes. O site é de física,
  instrumentação, eletrônica e visão computacional.
- Formas geométricas, traço uniforme, cantos levemente arredondados, bastante
  respiro. Um elemento principal por capa.
- Violeta como acento e neutros levemente lavanda. Uma segunda cor só quando o
  conteúdo pedir (dois sinais num gráfico, por exemplo), e com parcimônia.
- Evite: clip-art, gradiente arco-íris, brilho neon, sombra pesada, foto de
  banco de imagens, 3D brilhante, texto.

## Do claro para o escuro

Não inverta as cores: troque cada papel pelo equivalente da tabela.

| No claro | No escuro |
| --- | --- |
| Fundo `#f7f8fc` / `#f7f7fb` / `#ffffff` | `#0f121d` / `#1d2233` / `#171b2a` |
| Traço `#252639` | `#edf0fb` |
| Traço secundário `#5e6178` | `#cfcedd` |
| Grade `#e9eaf2` | `#2b3043` |
| Acento `#7055d8` | `#b6a2ff` |
| Tinta violeta `#f0ecff` | `#2c2646` |

Cuidados:

- Áreas grandes de branco puro viram áreas escuras, nunca o contrário: a
  capa escura não pode brilhar mais que a página em volta.
- Cores de apoio ficam um pouco mais claras e menos saturadas no escuro.
- Se houver um print de tela embutido, escureça a moldura em volta dele, não
  o print.
- Mesma composição, mesmas posições: só as cores mudam.

## Fundo do quadro

O site mostra a capa num quadro com fundo `#f7f7fb` (claro) ou `#1d2233`
(escuro) e borda fina. Um fundo de arte próximo desses tons faz a capa se
integrar; um fundo bem diferente (violeta cheio, por exemplo) vira destaque —
use quando o projeto merecer, e mantenha o mesmo nível de contraste no escuro.

## Tipografia (só se houver texto desenhado)

O site usa Plus Jakarta Sans nos títulos, Inter no texto e JetBrains Mono em
código. Letras desenhadas como forma devem lembrar a Plus Jakarta Sans:
geométrica, aberta, peso 700.
